Don't have a key? It's free:

  1. Create a free account at themoviedb.org and confirm your email.
  2. Go to Settings → API and request an API key. Choose personal use and fill out the short form.
  3. Copy the API Key (the short one), not the long "API Read Access Token", and paste it below.

TMDB's sign-up form works best on a computer.
